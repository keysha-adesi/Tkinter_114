Program Aplikasi Prediksi Prodi Pilihan dibuat menggunakan bahasa pemrograman Python dengan library Tkinter untuk membangun tampilan GUI (Graphical User Interface). Pada bagian awal program, `import tkinter as tk` digunakan untuk memanggil library Tkinter agar dapat membuat komponen antarmuka, sedangkan `messagebox` digunakan untuk menampilkan kotak pesan, meskipun pada program ini belum digunakan. Selanjutnya, `tk.Tk()` berfungsi membuat jendela utama aplikasi, `title()` memberikan judul aplikasi, `geometry()` mengatur ukuran jendela menjadi 500 × 650 piksel, dan `resizable(False, False)` mencegah ukuran jendela diubah. Komponen `Label` digunakan untuk menampilkan judul aplikasi dan informasi hasil prediksi, sedangkan `Frame` berfungsi sebagai wadah untuk mengelompokkan komponen agar tampilannya lebih rapi. Program menggunakan `for i in range(10)` untuk membuat sepuluh kolom input secara otomatis. Di dalam perulangan tersebut, `Entry` digunakan sebagai tempat memasukkan nilai mata pelajaran, sementara `f"Nilai Mata Pelajaran {i + 1}"` menghasilkan label nomor 1 sampai 10. Setiap kolom input disimpan ke dalam list `entries` menggunakan `append()` agar dapat diakses kembali. Metode `pack()` digunakan untuk mengatur posisi komponen, sedangkan `pady` dan `padx` memberikan jarak vertikal dan horizontal. Selanjutnya, `Button` digunakan untuk membuat tombol bertuliskan Hasil Prediksi. Parameter `command=hasil_prediksi` menghubungkan tombol dengan fungsi `hasil_prediksi()`, sehingga ketika tombol ditekan, fungsi tersebut dijalankan. Fungsi `hasil_prediksi()` menggunakan `hasil_label.config()` untuk mengubah teks pada label menjadi “Hasil Prediksi: TeknologiInformasi”. Komponen `font`, `bg`, dan `fg` digunakan untuk mengatur jenis huruf, warna latar belakang, dan warna teks, sedangkan `wraplength` membatasi lebar teks agar dapat berpindah baris jika diperlukan. Terakhir, `root.mainloop()` menjalankan aplikasi agar jendela tetap terbuka dan dapat menerima interaksi pengguna. Secara keseluruhan, program ini bertujuan untuk memahami dasar pembuatan GUI menggunakan Tkinter, mulai dari membuat jendela, menampilkan teks, menerima input, mengatur tata letak, hingga menjalankan fungsi melalui tombol. Hasil prediksi pada program ini masih bersifat tetap, yaitu TeknologiInformasi, tanpa dipengaruhi oleh nilai yang dimasukkan pengguna.
